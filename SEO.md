# SEO — Óleńsiz

Что уже настроено в коде и что нужно сделать руками. Второй список короткий,
но без него первый не работает: за вас никто сайт в Search Console не добавит.

Домен: **https://olensiz.zhengisbay.com**
Старый **songless.zhengisbay.com** отдаёт 301 на новый и не удалён намеренно —
он уже проиндексирован, и редирект передаёт накопленный вес.

---

## 1. Целевые запросы

Под что оптимизируем. Порядок — по ожидаемой ценности, а не по частоте.

**Казахские**
`өлең тап` · `әнді тап` · `songless қазақша` · `қазақша ән ойыны` ·
`әнді танып көр` · `қазақша ойын`

**Русские**
`угадай песню на казахском` · `угадай казахскую песню` · `songless казахстан` ·
`казахская музыкальная игра` · `игра угадай мелодию казахские песни`

**Латиница**
`olensiz` · `songless kazakh` · `qazaqsha an oiyny` · `olensiz zhengisbay`

Отдельно: название пишется `Óleńsiz`, но искать будут `Olensiz`. Поэтому
недиакритическое написание продублировано в `alt`, `keywords`, `alternateName`
в JSON-LD и в тексте `about.html` — иначе бренд-запрос не найдёт сам сайт.

## 2. Что настроено в коде

| Что | Где | Детали |
| --- | --- | --- |
| `<title>` и `description` | `index.html` | Казахский + русский дубль в одной строке: одна страница обслуживает оба языка |
| `og:description` | `index.html` | Русский текст — соцсети в KZ шарят чаще по-русски |
| `canonical` | `index.html`, `about.html` | Абсолютный, https, без слэша-хвоста |
| `hreflang` kk / ru / x-default | `index.html` | Разведены через `?lang=` — его читает `src/i18n.js` |
| JSON-LD `VideoGame` | `index.html` | name, alternateName, url, image, description, inLanguage, genre, author, publisher, offers (бесплатно) |
| Open Graph + Twitter Card | `index.html` | `summary_large_image`, og:image 1200×630 абсолютным URL |
| `og:image` | `og-image.png` | Генерируется `npm run og` из реальных обложек каталога |
| `sitemap.xml` | корень | Две страницы + hreflang-альтернативы |
| `robots.txt` | корень | Открыт весь сайт, закрыты `/data/` и `/scripts/`; ссылка на sitemap |
| Статический текст | `index.html` → `#about-static`, `about.html` | SPA без текста в разметке не ранжируется |
| Страница «Об игре» | `about.html` | Полная, видимая, со скроллом; в sitemap; ссылка из главной |

### Про статический текст — важная оговорка

В `index.html` есть блок `#about-static` с классом `.seo-copy`: он визуально
скрыт (игровой экран не скроллится, показывать этот текст поверх игры негде),
но содержит ровно то же, что человек видит в оверлее «Ойын туралы», и ссылку
на полную страницу `about.html`.

Это не клоакинг: содержание совпадает с тем, что доступно пользователю, и
отдельной «страницы для роботов» не существует. Но помните: скрытый текст
Google учитывает с понижающим коэффициентом. **Основную работу делает
`about.html`** — видимая страница с настоящим текстом. Если понадобится усилить
позиции, писать надо туда, а не в скрытый блок.

## 3. Что сделать руками

Отмечайте по мере выполнения.

- [ ] **Google Search Console** — [search.google.com/search-console](https://search.google.com/search-console)
  1. Добавить ресурс. Лучше **Domain property** для `zhengisbay.com` (подтверждение
     через DNS TXT в Cloudflare — заодно покроет все поддомены), либо URL-prefix
     для `https://olensiz.zhengisbay.com/`.
  2. Подтвердить владение.
  3. Sitemaps → добавить `sitemap.xml`.
  4. URL Inspection → `https://olensiz.zhengisbay.com/` → Request indexing.
     То же для `/about.html`.
- [ ] **Проверить переезд.** В Search Console старого адреса (если он был
      добавлен) использовать Change of Address на новый. Если старый ресурс не
      добавлялся — достаточно 301, он уже работает.
- [ ] **Яндекс.Вебмастер** — [webmaster.yandex.ru](https://webmaster.yandex.ru).
      В Казахстане у Яндекса заметная доля, и русские запросы приходят оттуда.
      Добавить сайт, подтвердить, отдать sitemap.
- [ ] **Проверить карточку ссылки** в мессенджерах: Telegram, WhatsApp,
      Instagram. Telegram кэширует превью — если картинка обновилась, а
      показывается старая, сбросить через `@WebpageBot`.
- [ ] **Проверить разметку**: [Rich Results Test](https://search.google.com/test/rich-results)
      и [Schema Validator](https://validator.schema.org/) для главной.
- [ ] **PageSpeed / Core Web Vitals**: [pagespeed.web.dev](https://pagespeed.web.dev/).
      Сайт статический и лёгкий, но LCP зависит от обложек с CDN Apple —
      посмотреть, не тянет ли он вниз.
- [ ] **Ссылки.** Органика на такой запрос приходит не от разметки, а от того,
      что игру расшарили. Самое полезное, что можно сделать: пост в KZ-тематических
      сообществах и телеграм-каналах про музыку.

## 4. Чего сознательно НЕ делаем

- **Не размножаем страницы под запросы.** «Угадай песню Кайрата Нуртаса»,
  «угадай той-песню» и подобные лендинги — это дорвеи. Они дадут краткий
  всплеск и долгую проблему.
- **Не прячем ключевые слова.** `keywords` в мете оставлен, потому что его
  читает Яндекс, но набивки там нет — только реальные формулировки запросов.
- **Не ставим счётчики и пиксели.** Аналитики на сайте нет вообще: игра ничего
  не собирает о человеке, и это стоит дороже, чем данные о трафике. Если
  аналитика понадобится, Cloudflare Web Analytics не требует cookies —
  но тогда прокси придётся включить (см. `SETUP.md`).
- **Не гонимся за мобильным трафиком.** Мобильной версии нет по заданию,
  и пока её нет, продвигать сайт в мобильной выдаче нечестно по отношению
  к пришедшему.

## 5. Как проверить, что ничего не сломалось

```bash
curl -sI https://songless.zhengisbay.com/ | head -3      # ожидаем 301 на olensiz
curl -s https://olensiz.zhengisbay.com/robots.txt        # ожидаем Sitemap:
curl -s https://olensiz.zhengisbay.com/sitemap.xml       # ожидаем два <url>
curl -s https://olensiz.zhengisbay.com/ | grep -c hreflang   # ожидаем 3
```
