# SEO — Óleńsiz

Как игру находят поиском: что уже сделано в коде и что нужно сделать руками.
Второй список короткий, но без него первый не работает — за вас никто сайт в
Search Console не добавит.

Домен: **https://olensiz.zhengisbay.com**
Старый **songless.zhengisbay.com** отдаёт 301 на новый и не удалён намеренно:
он уже проиндексирован, и редирект передаёт накопленный вес.

---

## 0. Главное в двух абзацах

Игра — одностраничное приложение. В её разметке нет ни названий песен, ни имён
исполнителей: каталог приезжает JSON-ом и живёт в памяти браузера. Для человека
это правильно, для поисковика — почти пустая страница, и ранжировать её не за
что.

Поэтому основную работу делают три настоящие страницы с текстом:
**главная** (заголовок, описание, статический блок «Об игре»),
**`about.html`** (правила, режимы, частые вопросы) и
**`catalog.html`** (136 исполнителей и 647 песен списком). Последняя —
самый ценный актив: именно она ловит запросы вида «угадай песню Кайрата
Нуртаса» и «казахские песни игра», потому что содержит настоящие имена.

## 1. Целевые запросы

Порядок — по ожидаемой ценности, а не по частоте.

**Казахские**
`өлең тап` · `әнді тап` · `songless қазақша` · `қазақша ән ойыны` ·
`әнді танып көр` · `қазақша ойын`

**Русские**
`угадай песню на казахском` · `угадай казахскую песню` · `songless казахстан` ·
`казахская музыкальная игра` · `игра угадай мелодию казахские песни`

**Латиница**
`olensiz` · `songless kazakh` · `qazaqsha an oiyny` · `olensiz zhengisbay`

**Длинный хвост** (его ловит `catalog.html`)
`<имя артиста> угадай песню` · `казахстанские исполнители список` ·
`той әндері ойын` · `qazaqsha әндер викторина`

Название пишется `Óleńsiz`, но искать будут `Olensiz`. Недиакритическое
написание продублировано в `alt`, `keywords`, `alternateName` в JSON-LD и в
тексте страниц — иначе бренд-запрос не найдёт сам сайт.

## 2. Что настроено в коде

| Что | Где | Детали |
| --- | --- | --- |
| `<title>` и `description` | `index.html` | Казахский + русский дубль: одна страница обслуживает оба языка |
| `canonical` | все страницы | Абсолютный, https, без хвостового слэша |
| `hreflang` kk / ru / x-default | `index.html` | Разведены через `?lang=` — его читает `src/i18n.js` |
| JSON-LD `VideoGame` + `WebSite` | `index.html` | name, alternateName, описание, языки, платформы, автор, издатель, бесплатность |
| JSON-LD `FAQPage` | `about.html` | 7 реальных вопросов — кандидат на расширенный сниппет |
| JSON-LD `CollectionPage` + `ItemList` | `catalog.html` | Список исполнителей как разметка |
| Open Graph + Twitter Card | `index.html` | `summary_large_image`, og:image 1200×630 абсолютным URL |
| `og-image.png` | корень | Генерируется `npm run og` из реальных обложек каталога |
| `sitemap.xml` | корень | Три страницы, hreflang-альтернативы, дата генерации |
| `robots.txt` | корень | Открыт весь сайт; закрыты `/scripts/`, `/.cache/` и исходники в `/data/`, но `data/tracks.json` **разрешён** |
| Страница «Каталог» | `catalog.html` | Генерируется `npm run seo` из `tracks.json` |
| Страница «Об игре» | `about.html` | Правила, режимы, FAQ, правовая заметка |
| Статический текст на главной | `index.html` → `#about-static` | Ссылки на обе текстовые страницы |
| 404 | `404.html` | `noindex`, ссылки обратно в игру — GitHub Pages отдаёт её сам |
| Мобильная версия | вся игра | Полноценная, ни один экран не прокручивается; mobile-first indexing это учитывает |
| PWA | `manifest.webmanifest`, `sw.js` | Устанавливается на домашний экран; оболочка работает офлайн |
| Скорость | — | Статика, без зависимостей и шрифтовых загрузок; `preconnect` к CDN Apple, `preload` каталога |

### Почему `robots.txt` разрешает `data/tracks.json`

Googlebot рендерит страницу как браузер. Если запретить ему каталог, он увидит
не игру, а экран ошибки загрузки — и решит, что сайт сломан. Закрыты только
исходники сборки (`artists-v2.csv`, отчёты), которые страницами не являются.

### Про скрытый текст на главной

Блок `#about-static` визуально скрыт: игровой экран не прокручивается, и
показать этот текст поверх игры негде. Это не клоакинг — содержание совпадает с
тем, что человек видит в оверлее «Об игре», и отдельной «страницы для роботов»
не существует. Но скрытый текст Google учитывает с понижающим коэффициентом,
поэтому усиливать позиции надо в `about.html` и `catalog.html`, а не там.

### Пересборка после изменений каталога

```bash
npm run build:catalog   # каталог
npm run seo             # catalog.html + sitemap.xml с новой датой
npm run og              # og-image.png (нужен поднятый npm run dev)
```

## 3. Что сделать руками

Порядок важен: первые три пункта дают 90% эффекта.

### 3.1. Google Search Console — обязательно

1. Откройте [search.google.com/search-console](https://search.google.com/search-console).
2. **Добавить ресурс → Домен** (`zhengisbay.com`). Это лучше, чем URL-префикс:
   один раз подтвердили — покрыты все поддомены, включая старый `songless`.
3. Подтверждение владения. **Файл `google99a4ad3c2c9ca121.html` уже лежит в
   корне сайта** — если Search Console предлагает способ «HTML-файл», просто
   нажмите «Подтвердить». Для ресурса типа «Домен» файла мало: там нужен
   DNS — **Cloudflare → DNS → Add record → тип TXT, Name `@`, Content —
   строка `google-site-verification=…` целиком**. TXT расходится за пару
   минут, иногда до часа.
4. **Sitemaps** → в поле ввести `sitemap.xml` → Отправить. Ожидаемо: «Успешно»,
   3 обнаруженных URL.
5. **Проверка URL** → вставить `https://olensiz.zhengisbay.com/` → **Запросить
   индексирование**. Повторить для `/about.html` и `/catalog.html`.
6. Через 3–7 дней зайти в **Покрытие** и убедиться, что страницы «Проиндексированы».

### 3.2. Яндекс.Вебмастер — обязательно для Казахстана

У Яндекса в KZ заметная доля, и русскоязычные запросы приходят во многом
оттуда.

1. [webmaster.yandex.ru](https://webmaster.yandex.ru) → **Добавить сайт** →
   `https://olensiz.zhengisbay.com`.
2. Подтверждение прав — любым из двух:
   - **DNS TXT** в Cloudflare (аналогично Google), либо
   - **Мета-тег**: скопируйте выданный `content` и раскомментируйте строку
     `yandex-verification` в `index.html` — она там уже подготовлена, вставьте
     код вместо `ВСТАВЬТЕ_КОД`, закоммитьте, дождитесь деплоя, нажмите
     «Проверить».
3. **Индексирование → Файлы Sitemap** → добавить
   `https://olensiz.zhengisbay.com/sitemap.xml`.
4. **Индексирование → Переобход страниц** → добавить три адреса.
5. В **Настройке индексирования → Региональность** укажите Казахстан:
   для русских запросов это заметно влияет.

### 3.3. Bing / Copilot — пять минут

[bing.com/webmasters](https://www.bing.com/webmasters) умеет **импортировать
всё из Google Search Console** одной кнопкой. Оттуда же данные попадают в
Copilot и DuckDuckGo.

### 3.4. Ссылки — то, что действительно двигает

Разметка помогает поиску понять сайт, но в топ выводят ссылки и переходы.
Самое полезное, что можно сделать руками:

- пост в казахстанских телеграм-каналах и чатах про музыку и IT;
- Reddit r/Kazakhstan, тематические сообщества во «ВКонтакте» и Threads;
- короткое видео в TikTok/Instagram с экраном игры — оттуда приходят и люди,
  и упоминания бренда, а бренд-запросы («olensiz игра») поиск любит;
- если о проекте напишет любой местный медиа-ресурс или блог — это ценнее
  всех технических правок вместе взятых.

### 3.5. Проверки после первого деплоя

- [ ] [Rich Results Test](https://search.google.com/test/rich-results) —
      главная (`VideoGame`, `WebSite`) и `about.html` (`FAQPage`).
- [ ] [Schema Validator](https://validator.schema.org/) — `catalog.html`.
- [ ] [PageSpeed Insights](https://pagespeed.web.dev/) — мобильная вкладка.
- [ ] Карточка ссылки в Telegram, WhatsApp и Instagram. Telegram кэширует
      превью: если картинка обновилась, а показывается старая — сбросить через
      бота `@WebpageBot`.
- [ ] Поиск по запросу `site:olensiz.zhengisbay.com` — покажет, что уже в индексе.

## 4. Чего сознательно НЕ делаем

- **Не размножаем страницы под запросы.** «Угадай песню Кайрата Нуртаса»,
  «угадай той-песню» отдельными лендингами — это дорвеи: краткий всплеск и
  долгая проблема. Один `catalog.html` с настоящим списком делает то же самое
  честно.
- **Не набиваем ключевые слова.** `keywords` оставлен, потому что его читает
  Яндекс, но там только реальные формулировки запросов.
- **Не ставим счётчики и пиксели.** Аналитики на сайте нет вообще: игра ничего
  не собирает о человеке. Если понадобится, Cloudflare Web Analytics не требует
  cookies — но тогда придётся включить прокси (см. `SETUP.md`).
- **Не выдумываем рейтинги.** `aggregateRating` в разметке без настоящих
  отзывов — это ложь разметкой, и за неё Google снимает расширенные сниппеты
  со всего сайта.

## 5. Как проверить, что ничего не сломалось

```bash
curl -sI https://songless.zhengisbay.com/ | head -3          # 301 на olensiz
curl -s https://olensiz.zhengisbay.com/robots.txt            # Sitemap: и Allow: /data/tracks.json
curl -s https://olensiz.zhengisbay.com/sitemap.xml | grep -c "<loc>"   # 3
curl -s https://olensiz.zhengisbay.com/ | grep -c hreflang   # 3
curl -s https://olensiz.zhengisbay.com/catalog.html | grep -c "<li><b>"  # ≈136
```

## 6. Чего ждать по срокам

Честно: новый домен в поиске появляется не мгновенно.

| Когда | Что происходит |
| --- | --- |
| 1–3 дня | Google находит сайт по sitemap, главная попадает в индекс |
| 1–2 недели | В индексе все три страницы; бренд-запрос `olensiz` начинает находить сайт |
| 1–2 месяца | Появляются позиции по «угадай казахскую песню» и подобным — если есть хоть несколько внешних ссылок |
| Дальше | Двигают только ссылки, упоминания и поведение: время на сайте, возвраты, шеры |

Технически сейчас сделано всё, что можно сделать кодом. Остальное — пункты 3.1–3.4.
